    📜 Инструкция
    Как пользоваться приложением
    ⚙️ Как работает приложение

    Python запускает локальный HTTP-сервер (порт 17832), браузер открывает интерфейс как обычный сайт. Данные — в SQLite-базе на вашем компьютере. Интернет не нужен.
    Плюсы: без интернета · данные только у вас · любой браузер
    Минусы: нужно держать Python-процесс открытым · нет системных push-уведомлений

    🔔 Уведомления

    Уведомления работают внутри браузера:
    • Всплывающие тосты (правый нижний угол) — появляются при каждом действии
    • Счётчик в заголовке вкладки — например (5) ОрфоДракон
    • Красный бейдж рядом с «Тренажёром» в меню
    Системные push-уведомления доступны только в оригинальном браузерном расширении.

    🔍 Поиск и ударения

    Введите слово → «Найти» → результат из словаря ФИПИ. Чтобы исправить: введите слово в блоке «Исправить ударение» → нажмите на мигающую гласную → «Сохранить». Всё в 3 клика.

    ✏️ Запятые

    Введите текст → «Расставить» (автоматически по союзам). Затем нажмите между словами чтобы добавить/убрать запятую. Если предложение уже есть в ваших карточках — загрузится сохранённый вариант. Результат нужно проверять!

    🎯 Тренажёр (SRS)

    «Знаю» → интервал растёт: 15 мин → 1 день → 3 дня → больше. «Не помню» → через ~10 минут снова. «Слабые места» — только карточки с ошибками за неделю.

    📋 ЕГЭ-режим

    10 вопросов с вариантами из ваших карточек. Таймер 10 минут. После — оценка 2–5 и разбор каждого вопроса. За правильные ответы начисляется XP и урон боссу.

    🏆 Геймификация

    XP → уровни → лиги (Бронзовый → Серебряный → Золотой → Платиновый → Изумрудный → Алмазный). Ежедневный сундук открывается после дневной цели — новый скин дракона (10 вариантов).

    💾 Экспорт и импорт

    На странице «Карточки» можно скачать все карточки в формате TXT (читаемый текстовый файл) и импортировать обратно. Для переноса на другой компьютер скопируйте TXT-файл и импортируйте там.
