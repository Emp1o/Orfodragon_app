# ОрфоДракон (OrfoDragon)

Десктопный тренажёр для подготовки к ЕГЭ/ОГЭ по русскому языку: отработка ударений и пунктуации в игровом формате (карточки, интервальное повторение, XP, стрики, лиги).

Приложение работает как связка **Python-бэкенд** (без внешних зависимостей, только стандартная библиотека) + **Electron-обёртка** для десктопа (Windows/macOS/Linux).

## Структура проекта

```
orfodragon/
├── main.py                   # точка входа Python-бэкенда
├── backend/                  # серверное ядро (0 внешних зависимостей)
│   ├── config.py              # константы: пути, порт, версия
│   ├── db/                    # SQLite-соединение и key-value хранилище
│   ├── domain/                 # бизнес-логика: карточки, SRS, геймификация, ЕГЭ-режим и т.д.
│   └── api/server.py           # HTTP-сервер и маршрутизация
├── electron/                  # десктопная обёртка
│   ├── main.js                 # главный процесс Electron
│   ├── preload.js               # preload-скрипт
│   └── package.json              # зависимости и конфиг electron-builder
├── data/                       # словарь ударений и список слов ФИПИ
├── static/index.html            # весь фронтенд (SPA)
├── icons/                       # иконки приложения
└── ARCHITECTURE.md               # подробное описание архитектуры
```

Полное описание того, как устроены модули и как они взаимодействуют — в [`ARCHITECTURE.md`](./ARCHITECTURE.md).

## Требования

- **Python 3.11+** (бэкенд использует только стандартную библиотеку, установка зависимостей не нужна)
- **Node.js 18+** и npm (для Electron-обёртки)

## Запуск в режиме разработки

### Только бэкенд (в браузере)

```bash
python main.py
```

Сервер сам найдёт свободный порт (начиная с `17832`) и откроет приложение в браузере по адресу `http://127.0.0.1:<port>`.

### Полное приложение (Electron)

```bash
cd electron
npm install
npm start
```

Electron сам поднимет Python-бэкенд в фоне и откроет окно приложения.

## Сборка десктопных дистрибутивов

Из папки `electron/`:

```bash
npm run dist:mac      # macOS (.dmg, .zip)
npm run dist:win      # Windows (nsis + portable)
npm run dist:linux    # Linux (rpm, AppImage)
```

Готовые сборки появятся в `electron/dist/` (папка не хранится в репозитории — генерируется локально).

## Данные пользователя

Прогресс хранится в SQLite-базе в стандартной пользовательской директории ОС:

- Windows: `%APPDATA%/OrfoDragon`
- macOS: `~/Library/Application Support/OrfoDragon`
- Linux: `$XDG_DATA_HOME/OrfoDragon` (по умолчанию `~/.local/share/OrfoDragon`)
